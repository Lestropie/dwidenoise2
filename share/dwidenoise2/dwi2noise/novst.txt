# dwi2noise noise level estimation schedule: "novst"
#
# The schedule engaged automatically when -vst_method none is given without -schedule.
#
# The multi-resolution "default" schedule refines its noise level estimate by feeding each
# iteration's estimate forward as the variance-stabilising transform of the next. With
# -vst_method none there is no such transform, so nothing couples the iterations and the
# additional rows would be wasted computation; a single pass is performed instead.
#
# The single row is deliberately the coarsest useful one: no rank density is available to a
# first (and only) iteration, so the kernel is sized by the rank-naive aspect ratio n ~ 2m,
# and the reconstruction grid is the command's default spatial sub-sampling factor.
#
# Note that "update_noise" is not a valid column for dwi2noise, which re-estimates the noise
# level in every iteration by definition (its output is that estimate).
#
spatial_subsample   temporal_subsample   kernel        smooth_noise
2                   1                    aspect=2.0    10.0
