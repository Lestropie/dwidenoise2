# dwidenoise2 noise level estimation and denoising schedule: "default"
#
# This file reproduces the default schedule of the dwidenoise2 command
# that was originally hard-coded into the source code.
# It additionally provides a starting point for authoring bespoke schedules.
#
# Format:
#  - One row per iteration of the multi-resolution noise level estimation.
#  - The first non-comment line names the columns; columns may appear in any
#    order, and any omitted column takes its default value.
#  - The final row corresponds to the reconstruction (denoising) pass.
#
# Columns:
#  - spatial_subsample   : per-axis spatial subsampling factor; a single integer
#                          (isotropic) or a comma-separated triplet "x,y,z". Larger
#                          values perform fewer PCAs (coarser, faster). Default: 2.
#  - temporal_subsample  : fraction of volumes (along the supra-spatial axes) used
#                          for noise level estimation in this iteration, within
#                          (0.0, 1.0]; the subset is drawn stratified by demeaning
#                          group. Default: 1.0 (all volumes). For dwidenoise2 the
#                          final (reconstruction) row must be 1.0.
#  - partitions          : split each PCA patch's volumes into this many partitions,
#                          performing an independent decomposition per partition and
#                          pooling the eigenspectra; this reduces PCA cost by ~partitions^2
#                          on large series. The patch voxel count is sized from the
#                          smallest partition so each partition keeps the target Casorati
#                          aspect ratio. Default: 1 (no partitioning). Mutually exclusive
#                          with max_partition_size.
#  - max_partition_size  : an alternative to "partitions": the maximum number of volumes
#                          per partition, from which the partition count is derived as
#                          ceil(num_volumes / max_partition_size) (after any temporal
#                          sub-sampling). "none" disables it. Default: none. Mutually
#                          exclusive with partitions.
#  - kernel_multiplier   : multiplier applied to the PCA patch size. Default: 1.
#  - update_noise        : whether the noise level estimate is (re)computed in this
#                          iteration ("true" or "false"). Must be true for any
#                          non-final iteration. Default: true for non-final rows;
#                          for the final row, false (carry the prior estimate
#                          through the reconstruction).
#  - smooth_noise        : whether to smooth the estimated noise map before it is
#                          passed to the next iteration ("true" or "false").
#                          Default: false.
#                          May be true only when update_noise is true in the same
#                          iteration (an iteration that does not (re)estimate the
#                          noise level has no freshly estimated map to smooth).
#
spatial_subsample   kernel_multiplier   update_noise   smooth_noise
8                   16                  true           false
4                   4                   true           false
2                   1                   true           true
2                   1                   false          false
